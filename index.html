    How the system works

    The farmer picks a sampling point on the dashboard and clicks Go. The server queues a GOTO command.
    The ESP32 robot polls the server every 3 seconds, receives the command and the current thresholds, and drives to the point.
    A servo lowers the capacitive probe into the soil. After 600 ms the robot averages 8 ADC samples and reads the DS18B20 temperature sensor, then raises the probe.
    The robot converts the raw value to moisture % (3000 = dry air, 1200 = water) and sends it to the server with its device key.
    The server validates the reading, classifies it as dry, normal or wet with the current thresholds, adds a recommendation and stores it in MySQL.
    The dashboard refreshes every 5 seconds and shows the reading, the recommendation and the updated field overview.
    If Wi-Fi is lost, the robot keeps up to 20 readings in a buffer and sends them, marked as buffered, when the connection returns.

    Decision rules

    MoistureStatusRecommendation

    Ambient temperature refines the advice but never overrides the soil reading. A wet point is never told to irrigate.
